# Kseniia Kalashnikova — personal site

Static site, no build step.

## Deploy to Vercel via GitHub
1. Create a new GitHub repository and upload all files from this folder to the repository root.
2. In Vercel: Add New → Project → import the repository.
3. Framework preset: **Other**. Build command: empty. Output directory: `./` (root).
4. Deploy.

## Request form
Requests go to kseniia.kklsh@gmail.com via FormSubmit.
After the first request on the live site, FormSubmit sends a confirmation email — click the activation button once.
